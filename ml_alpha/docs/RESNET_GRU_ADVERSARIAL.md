# ResNet-GRU 对抗训练因子

东方证券第 98 篇的 Model1 将对抗样本 MSE 加入原始损失。`resnet_gru_week_adv` 和 `resnet_gru_msnew_adv` 分别复用现有周线和半小时 ResNet-GRU。数据源、预处理、股票池、64 个分量的等权聚合以及验证与预测口径随各自基准配置。

在已预处理的训练张量上，以预测 MSE 为目标迭代梯度上升。每个字段的扰动上限为当前训练批次的字段标准差乘以 `epsilon=0.02`，步长为标准差乘以 `step_size=0.01`，迭代 `steps=2`。扰动按 (L_\infty) 范数投影回预算范围，常数通道不变。报告给出扰动公式但未披露这些数值。

训练先反传干净样本的标准化标签 MSE 和弱因子 Gram 矩阵惩罚，再累积扰动样本对同一份标准化标签的 MSE 梯度，执行一次优化器更新。扰动损失默认 `weight=1.0`，设为零时直接走基准训练路径。BatchNorm 的运行统计量只用干净样本更新。扰动搜索的每一步只求输入梯度，释放上一步计算图后再继续。

验证用干净输入的逐日 Pearson IC 选权重，预测依旧每股票每交易日写一个正式因子值。两套配置使用独立权重目录 `data/model_workspace/<factor_id>/artifacts/annual_YYYY/`。对抗样本在原训练设备上生成和消费，数据读取和存储复用基准实现。
