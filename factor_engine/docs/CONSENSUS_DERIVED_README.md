# Analyst Consensus Derived Data / 一致预期派生数据说明

This document describes the daily wide analyst-consensus dataset generated by
`derive-consensus`.

本文说明 `derive-consensus` 生成的日频宽表一致预期数据，供后续因子开发、
数据检查和增量维护使用。

## Output / 输出位置

Output path:

```text
data/derived/stock/consensus/{trade_date}.parquet
```

输出路径：

```text
data/derived/stock/consensus/{trade_date}.parquet
```

Each file is one trading day. Each row is one stock. The table is intentionally
wide: only final consensus metric columns are written. Helper columns such as
`*_type`, `*_inst_count`, and `*_hisdate` are not output.

每个文件对应一个交易日，每行对应一只股票。当前采用宽表格式，只输出最终一致
预期指标值，不输出 `*_type`、`*_inst_count`、`*_hisdate` 等辅助状态列。

## CLI / 生成命令

Full history example:

```powershell
cargo run --release --manifest-path factor_engine\Cargo.toml -- derive-consensus `
  --start-date 20110101 `
  --end-date 20260424 `
  --date-batch-size 120 `
  --overwrite true
```

全量历史生成示例：

```powershell
cargo run --release --manifest-path factor_engine\Cargo.toml -- derive-consensus `
  --start-date 20110101 `
  --end-date 20260424 `
  --date-batch-size 120 `
  --overwrite true
```

Notes / 说明：

- `--overwrite true` overwrites existing daily parquet files. It is the default.
- `--overwrite false` skips existing daily files.
- `--date-batch-size` controls sequential processing batches. Progress is still
  reported by output trading date because one parquet file is written per date.
- `--overwrite true` 会覆盖已有日文件，且为默认值。
- `--overwrite false` 会跳过已有日文件。
- `--date-batch-size` 控制顺序处理批次；进度条仍按输出日期推进，因为每天
  写一个 parquet。

## Inputs / 输入数据

Analyst detail data / 分析师明细：

- Dataset: `StockAnalystReport`
- Local path: `data/stock_data/analyst_report/{year}.parquet`
- Main fields used:
  - `ts_code`
  - `report_date`
  - `create_time`
  - `org_name`
  - `author_name`
  - `quarter`
  - `op_rt`
  - `np`
  - `eps`
  - `rating`
  - `min_price`

Market data / 日频市场数据：

- `StockDailyPv`: `close`, `pre_close`

Financial PIT data / 财报 PIT 数据：

- `StockIncome`, consolidated annual preference:
  - `revenue`
  - `n_income_attr_p`
  - `basic_eps`
- `StockBalanceSheet`, consolidated preference:
  - `total_hldr_eqy_exc_min_int`

Financial actual values are visible only when the PIT statement record satisfies
`f_ann_date.or(ann_date) <= trade_date`.

真实财务值只在对应 PIT 财报记录满足 `f_ann_date.or(ann_date) <= trade_date`
后可见，避免未来数据。

## Rows And Columns / 行与列

Base columns / 基础列：

- `trade_date`
- `ts_code`

Annual suffixes / 年度后缀：

- `fy0`
- `fy1`
- `fy2`
- `fy3`

The fiscal-year anchor follows the current Chaoyang Yongxu convention used in
the generator:

```text
if trade_date month-day < 0501:
    fy0 base year = trade_year - 2
else:
    fy0 base year = trade_year - 1

fy1 = fy0 + 1
fy2 = fy0 + 2
fy3 = fy0 + 3
```

财年锚点规则：

```text
如果 trade_date 的月日 < 0501:
    fy0 基准年 = trade_year - 2
否则:
    fy0 基准年 = trade_year - 1

fy1 = fy0 + 1
fy2 = fy0 + 2
fy3 = fy0 + 3
```

## Annual Metrics / 年度指标

The following annual metrics are output for every suffix `fy0..fy3`.

以下指标均输出 `fy0..fy3` 四个版本。

### `con_or_fy*`

Consensus operating revenue.

一致预期营业收入。

Construction / 合成口径：

- If actual annual financial revenue is PIT-visible, use actual `revenue`.
- Otherwise use analyst forecasts from `op_rt`.
- Forecast rows use only annual forecasts where `quarter = YYYYQ4`.
- Analyst abnormal values such as `NaN`, `inf`, and `-inf` are dropped before
  aggregation.

- 如果年度真实财报营业收入已 PIT 可见，使用真实 `revenue`。
- 否则使用分析师明细 `op_rt`。
- 只使用 `quarter = YYYYQ4` 的年度预测。
- 分析师明细中的 `NaN`、`inf`、`-inf` 等异常值会先剔除。

### `con_np_fy*`

Consensus net profit attributable to parent.

一致预期归母净利润。

Construction / 合成口径：

- If actual annual financial net profit is PIT-visible, use actual
  `n_income_attr_p`.
- Otherwise use analyst forecasts from `np`.
- Forecast rows use only annual forecasts where `quarter = YYYYQ4`.

- 如果年度真实归母净利润已 PIT 可见，使用真实 `n_income_attr_p`。
- 否则使用分析师明细 `np`。
- 只使用 `quarter = YYYYQ4` 的年度预测。

### `con_eps_fy*`

Consensus EPS.

一致预期 EPS。

Construction / 合成口径：

- If actual annual financial EPS is PIT-visible, use actual `basic_eps`.
- Otherwise use analyst forecasts from `eps`.
- Forecast rows use only annual forecasts where `quarter = YYYYQ4`.

- 如果年度真实 EPS 已 PIT 可见，使用真实 `basic_eps`。
- 否则使用分析师明细 `eps`。
- 只使用 `quarter = YYYYQ4` 的年度预测。

### Annual Forecast Aggregation / 年度预测聚合

For `con_or`, `con_np`, and `con_eps`, the generator uses the following
stateful forecast rules:

`con_or`、`con_np`、`con_eps` 的分析师预测聚合采用以下状态机规则：

- Keep the latest valid forecast per `ts_code + fiscal_year + metric + org_name`.
- Strict window: forecasts in the past 90 natural days. If there are at least
  6 institutions, use equal-weight aggregation.
- Loose window: if strict samples are insufficient, use available forecasts in
  the past 120 natural days.
- Carry window: if no loose forecast exists, carry available forecasts in the
  past 183 natural days.
- If no forecast is available, output null.
- 每个 `股票 + 财年 + 指标 + 机构` 只保留最新有效预测。
- 严格窗口：过去 90 个自然日内预测，机构数至少 6 家时等权聚合。
- 宽松窗口：严格样本不足时，使用过去 120 个自然日内可用预测。
- 沿用窗口：如果 120 日内没有可用预测，沿用过去 183 个自然日内可用预测。
- 完全没有可用预测时输出空值。

The original document mentions institution/time influence weights but does not
provide the exact weighting function. The current implementation uses
deterministic equal weighting and keeps the aggregation point replaceable in
code.

原始文档提到机构影响力和发布时间影响力，但没有给出具体权重函数。当前实现
使用确定性的等权聚合，并保留后续替换权重模型的代码位置。

### `con_na_fy*`

Consensus net assets.

一致预期净资产。

Formula / 公式：

```text
con_na = latest PIT visible total_hldr_eqy_exc_min_int + 0 + con_np
```

Notes / 说明：

- Fundraising amount is not available locally and is treated as `0`.
- `total_hldr_eqy_exc_min_int <= 0` is invalid and makes `con_na` null.
- 募集资金本地无数据，按 `0` 处理。
- `total_hldr_eqy_exc_min_int <= 0` 时 `con_na` 为空。

### `con_pb_fy*`

Consensus PB.

一致预期市净率。

Formula / 公式：

```text
shares = con_np / con_eps
con_pb = close_price * shares / con_na
```

`close_price` uses `close`; if `close <= 0` or missing, it falls back to
`pre_close`.

`close_price` 优先使用 `close`；若 `close <= 0` 或缺失，则使用 `pre_close`。

### `con_ps_fy*`

Consensus PS.

一致预期市销率。

Formula / 公式：

```text
shares = con_np / con_eps
con_ps = close_price * shares / con_or
```

### `con_pe_fy*`

Consensus PE.

一致预期市盈率。

Formula / 公式：

```text
con_pe = close_price / con_eps
```

### `con_roe_fy*`

Consensus ROE.

一致预期净资产收益率。

Formula / 公式：

```text
con_roe = 100 * con_np / con_na
```

### `con_or_yoy_fy*`

Consensus operating revenue year-on-year growth.

一致预期营业收入同比。

Formula / 公式：

```text
con_or_yoy = 100 * (con_or_t - con_or_{t-1}) / abs(con_or_{t-1})
```

### `con_np_yoy_fy*`

Consensus net profit year-on-year growth.

一致预期净利润同比。

Formula / 公式：

```text
con_np_yoy = 100 * (con_np_t - con_np_{t-1}) / abs(con_np_{t-1})
```

### `con_npcgrate_2y_fy*`

Consensus two-year net-profit growth transform.

一致预期两年净利润增长变换。

The current project convention is user-adjusted from the original document:
keep the square-root transform, but use an absolute-denominator change rate
inside the square root.

当前项目口径是在原文基础上的用户确认调整：保留平方根变换，但平方根内部改为
使用绝对值分母的变化幅度。

Formula / 公式：

```text
base_np = con_np_{fyX-2}
current_np = con_np_{fyX}
raw_change = (current_np - base_np) / abs(base_np)

con_npcgrate_2y_fyX = 100 * (sqrt(raw_change) - 1)
```

Null rules / 空值规则：

- `base_np` missing or `abs(base_np) <= eps`: null
- `current_np` missing: null
- `raw_change < 0`: null

- `base_np` 缺失或 `abs(base_np) <= eps`：空
- `current_np` 缺失：空
- `raw_change < 0`：空

### `con_peg_fy*`

Consensus PEG.

一致预期 PEG。

Formula / 公式：

```text
con_peg = con_pe / con_npcgrate_2y
```

Null rules / 空值规则：

- `con_pe < 0`: null
- `con_npcgrate_2y <= 0`: null
- any input missing: null

- `con_pe < 0`：空
- `con_npcgrate_2y <= 0`：空
- 任一输入缺失：空

## Rolling Metrics / 滚动指标

Rolling metrics use calendar-year interpolation:

滚动指标采用自然年插值：

```text
w = days_until_year_end(trade_date) / 365
current_roll = value_current_calendar_year * w
             + value_next_calendar_year * (1 - w)

historical_roll = value_previous_calendar_year * w
                + value_current_calendar_year * (1 - w)
```

Output rolling columns / 输出滚动列：

- `con_or_roll`
- `con_np_roll`
- `con_eps_roll`
- `con_na_roll`
- `con_pb_roll`
- `con_ps_roll`
- `con_pe_roll`
- `con_peg_roll`
- `con_roe_roll`
- `con_or_yoy_roll`
- `con_np_yoy_roll`
- `con_npcgrate_2y_roll`

### Rolling Valuation / 滚动估值

```text
con_pe_roll = close_price / con_eps_roll
shares_roll = con_np_roll / con_eps_roll
con_pb_roll = close_price * shares_roll / con_na_roll
con_ps_roll = close_price * shares_roll / con_or_roll
con_roe_roll = 100 * con_np_roll / con_na_roll
```

### Rolling YoY / 滚动同比

```text
con_or_yoy_roll = 100 * (con_or_roll - historical_or_roll) / abs(historical_or_roll)
con_np_yoy_roll = 100 * (con_np_roll - historical_np_roll) / abs(historical_np_roll)
```

### `con_npcgrate_2y_roll`

Rolling net-profit growth transform.

滚动净利润增长变换。

Formula / 公式：

```text
future_roll_np =
    con_np_calendar_year * w
  + con_np_next_calendar_year * (1 - w)

historical_roll_np =
    con_np_{calendar_year-2} * w
  + con_np_{calendar_year-1} * (1 - w)

raw_change = (future_roll_np - historical_roll_np) / abs(historical_roll_np)

con_npcgrate_2y_roll = 100 * (sqrt(raw_change) - 1)
```

Null rules are the same as annual `con_npcgrate_2y_fy*`.

空值规则同年度 `con_npcgrate_2y_fy*`。

### `con_peg_roll`

Rolling PEG.

滚动 PEG。

Formula / 公式：

```text
con_peg_roll = con_pe_roll / con_npcgrate_2y_roll
```

Null rules / 空值规则：

- `con_pe_roll < 0`: null
- `con_npcgrate_2y_roll <= 0`: null
- any input missing: null

- `con_pe_roll < 0`：空
- `con_npcgrate_2y_roll <= 0`：空
- 任一输入缺失：空

## Forecast Revision Metrics / 预测变化率

Output columns / 输出列：

- `con_npgrate_1w`
- `con_npgrate_4w`
- `con_npgrate_13w`
- `con_npgrate_26w`
- `con_npgrate_52w`

Formula / 公式：

```text
con_npgrate_X =
    100 * (current_con_np_fy0 - previous_con_np_fy0)
        / abs(previous_con_np_fy0)
```

Anchor dates use natural-day offsets and then map to the latest open trading day
on or before the anchor:

锚点使用自然日偏移，并映射到该自然日前最近一个开市交易日：

```text
1w  = 7 natural days
4w  = 28 natural days
13w = 91 natural days
26w = 182 natural days
52w = 364 natural days
```

## Rating And Target Price / 评级与目标价

### `con_rating_strength`

Consensus rating strength.

一致预期评级强度。

Mapping / 映射：

```text
买入 / 强烈推荐 / 推荐 / buy / strong buy        -> 1.00
增持 / 优于大市 / 跑赢行业 / outperform / overweight -> 0.75
中性 / 持有 / 无 / neutral / hold                 -> 0.50
减持 / 低于大市 / underperform / underweight       -> 0.25
卖出 / sell                                      -> 0.00
```

Aggregation / 聚合：

- Keep the latest valid rating per `ts_code + org_name`.
- Use ratings in the past 90 natural days.
- Output equal-weight mean of mapped strengths.
- 每个 `股票 + 机构` 保留最新有效评级。
- 使用过去 90 个自然日内评级。
- 输出映射强度的等权均值。

### `con_target_price`

Consensus target price.

一致预期目标价。

Aggregation / 聚合：

- Keep the latest valid `min_price` per `ts_code + org_name`.
- Use target prices in the past 90 natural days.
- Output equal-weight mean.
- 每个 `股票 + 机构` 保留最新有效 `min_price`。
- 使用过去 90 个自然日内目标价。
- 输出等权均值。

## State, PIT, And Performance / 状态机、PIT 与性能

`derive-consensus` is a derived-data generator, not a normal factor provider.
It uses a cross-batch state machine:

`derive-consensus` 是派生数据生成器，不是普通因子 provider。它使用跨 batch
状态机：

- The first batch warms up analyst reports from `start_date - 600 natural days`.
- Later batches only ingest newly visible analyst reports.
- Forecast/rating/target states are pruned to their effective windows.
- `con_np_fy0` history is retained for the revision metrics.
- Annual base snapshots are cached by `ts_code + fiscal_year` and recomputed
  only when analyst reports, PIT financial records, or forecast window expiry
  require it.

- 第一批从 `start_date - 600` 个自然日开始 warmup。
- 后续 batch 只增量 ingest 新出现的分析师明细。
- 预测、评级、目标价状态只保留有效窗口。
- `con_np_fy0` 历史用于计算预测变化率。
- 年度基础 snapshot 按 `股票 + 财年` 缓存，仅在分析师明细、PIT 财报记录或窗口
  过期导致状态变化时重算。

Daily market columns and final valuation columns are still computed on each
output trading day, because price can change daily.

日频价格和最终估值类列每天计算，因为价格是日频快变量。

## Development Notes / 后续开发注意事项

- Do not reintroduce helper output columns unless there is a clear downstream
  use case. Current files are intended to contain final metrics only.
- Keep abnormal analyst numeric values filtered before state ingestion.
- Do not use future financial statements. Always query financial actuals through
  PIT readers using `trade_date`.
- If the original vendor weighting functions become available, replace the
  forecast aggregation model in one place instead of changing downstream column
  formulas.
- 如果没有明确下游需求，不要重新输出辅助列。当前文件只保留最终指标值。
- 分析师数值异常值必须在进入状态机前过滤。
- 不得使用未来财报；真实财务值必须通过 PIT reader 按 `trade_date` 查询。
- 如果后续拿到原始供应商的机构/时间权重函数，应只替换聚合模型，不应改下游
  列公式。
