# DFQ-HIST / mdl_000025

参考东方证券 2024-02-07《DFQ-HIST：添加图信息的选股因子挖掘系统》，
重点为第 6–9、13、16–17 页。结构图和公式优先于原版
[HIST 参考实现](https://github.com/Wentao-Xu/HIST/blob/main/model.py)；
本项目独立实现，未引入 Qlib 或复制研究数据。

## 本地版本范围

这是 **因子合成模型**，管理在 `models/mdl_000025.toml`、
`model_registry.toml`，不占用正式端到端因子的语义 ID。
用户确认的首版范围：

- 本地全部有效正式因子的历史序列；自动发现时排除 `model_generated`、
  `deprecated` 和自身模型列。没有研报私有的 60 基础特征及 300 GP/RL 因子清单，
  不宣称已复现这两组数据，也不加入量价独立分支。
- 单个 `future_vwap_return_10d` 标签；不做三标签或多种子集成。
- 年度重训，近 36 个月前 33 个月训练、后 3 个月验证，目标截面每 5 个交易日采样，
  每个目标截面使用过去 **60 个连续交易日**历史，包含当日。
- 单种子 42；中证全市场口径 `mkt_all`，剔除 ST、BJ，不剔除涨跌停。
- 预定义概念只用主营业务 **I 分类**，不使用 P 产品分类、D 地区分类，
  不使用当前静态行业字段回填历史。

默认首个预测年度 2019，首窗口为 2016-01～2018-09 训练、
2018-10～2018-12 验证；正式预测到 2026-04-24。
日期边界、标签成熟和训练/验证隔离均由公共 `build_windows` 完成。
10 日 VWAP 的标签终点是 t+11，训练日 T 最后可用样本不晚于 T-11，
训练/验证交界也隔离相应标签。60 日输入不足、股票历史不连续时不建立该样本；
缺少整个历史日期文件则报错，不能以零填充一整天。

## 概念数据

本地 `data/chn_stock_data/mainbz/<year>.parquet` 已有 2009 年起数据，
字段包括 `ts_code/end_date/bz_type/bz_item`，但没有公告日期。
2023 年文件包含 134,231 行，其中 I 分类 23,935 行（尚未做半年度筛选及去重）。

Rust `derive-hist-concepts` 生产日度稀疏股票—概念关系：

1. 仅取 I 分类的 06-30、12-31 报告。年报于次年 05-01 生效，
   半年报于当年 09-01 生效，非交易日由后续交易日自然承接。
   例如 2023-12-31 期数据从 2024-05-01 起可用。
2. 同一股票取截至目标日最新可用报告，新的列表替换旧列表。
   未披露更新时延续上一期；新报告仅含被排除的泛化项时清空旧概念。
3. `bz_item` 去掉空白后按精确字符串分组，概念 ID 为 `I:<名称>`；
   不做未披露的同义词合并，不利用未来收益筛选概念。
4. 剔除空项和明确列举的泛化项，包括“合计、总计、其他、其它、其他业务、
   其它业务、其他行业、其它行业、行业合计、主营业务合计、营业收入合计、
   未分配、抵销、抵消、分部间抵销、分部间抵消”。此规则写入数据 manifest。
5. 同股票同概念去重，关系本身为二元值；不使用营业收入权重。
   概念初始化时才使用当日 `daily/basic.total_mv` 总市值加权。

此时间规则来自研报，并非逐条实际公告日。原始历史修订无法通过本地缺失的
公告版本恢复；这是本地数据的限制。研报也未公布概念清洗及映射表，
因此本版概念数量不会被强制调整成研报的 1,218 个。

路径：`data/derived/stock/hist_concepts/<year>/<date>.parquet`，
Snappy 压缩，字段为：

```text
trade_date: int32
ts_code: string
concept_id: string
end_date: int32
available_date: int32
```

根目录 `manifest.json` 版本 `hist_mainbz_i_v1`。
Python 校验数据版本、重复关系及可用日期，不会静默改用其他行业图。
部分股票没有主营业务概念时，仍保留在完整截面，可由概念修正获取其他股票共享信息。
若整个截面没有概念，则跳过预定义概念分支，保留隐藏概念和个股分支。
缺少概念文件或市值数据时明确报错。

## 模型结构

```text
N只股票 × 60交易日 × F个正式因子
                  ↓
        2层GRU，隐藏维128
                  ↓ X0
    总市值加权的预定义概念初始化
    → 股票到概念的余弦softmax修正
    → 概念到股票的余弦softmax聚合
    → 全连接 → backcast B0 / forecast Y0
                  ↓ X1 = X0 − B0
    股票作为隐藏概念锚点，TopK邻居构图
    → 隐藏概念加权汇集 → 余弦注意力
    → 全连接 → backcast B1 / forecast Y1
                  ↓ X2 = X1 − B1
       个股全连接 + LeakyReLU → Y2
                  ↓
       Linear(Y0 + Y1 + Y2) → 每股一个分数
```

预定义概念有两次不同方向的 softmax：

- 初始概念 E0 是所属股票 X0 的市值加权均值，权重按每个概念归一化。
- 修正 E1 时，每个概念与**全部股票**计算余弦相似度，沿股票维 softmax。
  这是 DFQ 相对上游代码直接点积的修正，不能替换成未归一化点积。
- 回到股票时，每只股票与**全部修正后概念**计算余弦相似度，沿概念维 softmax。

隐藏概念从 X1 计算，避免重新把已解释的预定义概念作为输入：

- 每只股票选除自身外余弦相似度最大的 20 个锚点；不足则选 N-1 个。
- 保留这些余弦权重，包括负值，其余连接置零。按入边汇集股票残差，
  被选中的锚点加上自身贡献；这延续 HIST 参考实现的锚点处理。
- 无入边锚点和零向量概念不参与后续注意力。按全体有效隐藏概念再次进行
  余弦 softmax 聚合，不通过股票分块裁剪关系。
- 两个 backcast 相减，三个 forecast 向量相加后统一映射为标量。
  不加入 XGBoost、Ranker 或与 mdl_000024 相同的正交因子损失。

60 日序列、K=20、Dropout=0.1 等是用户确认的项目参数；
GRU 的 2 层和 128 维由研报明确披露。模型输出是连续选股分数，
不是未经变换的未来收益率百分数。

## 训练和防泄漏

公共 `FactorSequenceProvider` 复用现有因子历史逻辑；mdl_000024 也沿用该公共基类，
原有关系图、预处理和输出不变。

- 每个历史日期独立做 MAD5 截尾、截面 z-score、缺失填 0；
  在加入标签之前完成，未来标签缺失不能改变归一化或图节点。
- 图节点为当前股票池中拥有连续 60 日历史的股票；保留无标签节点，
  只在损失及验证指标处屏蔽缺失标签，避免预测期与训练期构图语义变化。
- 标签在每个训练／验证截面做平均秩百分位，再 z-score，MSE 拟合。
  常数标签或不足两只有效股票的日期不用于损失或验证指标。
- 每轮从已经按 5 日采样的训练日期中无放回选最多 100 个日期，
  用单种子控制日期选择；选中后按日期顺序遍历。不会每轮仅选固定前100天。
- Adam、lr=0.001、weight_decay=1e-5，梯度范数裁剪为5；
  上限100轮，验证集日均 Pearson IC 连续20轮无提升早停。
- 每轮结束暂时用最近最多5轮参数平均值计算验证IC，然后恢复该轮真实参数；
  优化器状态持续保留。最终模型保存验证IC最优的**平均参数**。
  这是参数平均，不是五种子预测集成。

## 内存、显存和存储

- 不缓存整个训练期的时序三维矩阵，不落盘预处理表。
  日度因子标准化结果使用现有有界内存 LRU，预算512 MiB。
  该预算只约束 LRU，不代表进程总内存。
- 每个日期按最多3000只股票读取并编码序列。CPU输入结合 GRU 梯度检查点，
  在反向传播时重算该编码块，降低显存占用；这会增加计算时间。
  **3000不是图节点上限**。同日全部股票编码完成后统一建立概念交互。
- 注意力以512个查询为块，但每个块仍访问全部 key，softmax 分母完整。
  注意力梯度检查点避免持有全部股票×概念激活。
- 隐藏概念 TopK 相似度按查询块计算，稀疏入边聚合，不持久化 N×N 关系矩阵。
  计算复杂度仍包含股票两两比较，不能视为与普通GRU同等开销。
- 原始因子序列的一日 CPU 输入体积约 `N × 60 × F × 4 bytes`。
  例如5000只股票、400因子约458 MiB；此项之外还需 LRU、模型、标签及工作内存。
- Rust产物仅稀疏概念边及可用日期，不保存市值、不保存稠密图；
  `--date-batch-size` 表示一次派生／写出的**目标交易日数**，不是预读天数。
  批内暂存这些日期的边表，默认20；设120会提高这部分峰值内存。
  以实际边数、字符串分布和Snappy压缩后文件大小衡量磁盘占用，代码不预留固定磁盘预算。
