# ASTGNN 日频基本面因子

`astgnn_lfq_daily` 是东方证券第 104 篇的项目版基本面分支。输入为 56 个 PIT 指标与 56 个缺失标记。模型每天为每只股票生成 64 个 alpha 分量，以等权均值作为正式因子。派生表保留原始比例、增长率、周转天数及指标定义中的 EP 滚动 z-score。读取时对每个交易日的有限值逐列做 MAD5 缩尾和截面 z-score。再将缺失位置填零，保留原缺失标记。模型输入预处理在内存完成，现有派生表可直接复用，旧输入口径的模型权重需要重训。

## 输入清单与字段

利润表、现金流量表使用单季合并记录，流量变量以最近四个季度求和为 TTM。财务计算以最近可见利润表季度为锚，没有利润表时依次尝试资产负债表、现金流量表。同比和跨表计算按季度对齐。财报使用 `f_ann_date`，缺失时用 `ann_date`。取当前截面已披露的版本，较晚的修订从披露后生效。

| 组别 | 指标与来源（每组 8 项） |
| --- | --- |
| 估值与回报 | 利润 TTM / 总市值、该 EP 的 252 日 z-score（至少 60 个有限观察）、`dv_ttm`、归母权益 / 总市值、营收 TTM / 总市值、经营现金流 TTM / 总市值、自由现金流 TTM / 总市值、EBIT / EV。市值取 `total_mv`，EV 为市值加有息负债减货币资金。 |
| 盈利 | ROE、ROA、ROIC、毛利 / 平均资产、毛利率、营业利润率、净利率、扣非净利率代理。ROE 用归母权益，ROIC 用税后 EBIT / 平均投入资本。 |
| 增长 | 扣非利润同比代理、营收同比、营业利润同比、归母净利润同比、经营现金流同比、总资产同比、毛利率同比变化、ROE 同比变化。增长率用上期绝对值作基数。 |
| 现金流与盈余 | 经营现金流 / 营收、自由现金流 / 营收、经营现金流 / 归母净利润、总应计项 / 平均资产、销售收现率、资本支出 / 营收、研发费用率、扣非利润占比代理。自由现金流取经营现金流减购建长期资产现金支出。 |
| 偿债 | 资产负债率、有息负债率、净负债 / 权益、流动比率、速动比率、利息保障倍数、货币资金 / 资产、短期有息负债占比。利息用 `fin_exp_int_exp`，缺失时取 `int_exp`。 |
| 营运效率 | 总资产周转率、固定资产周转率、应收周转天数、存货周转天数、应付周转天数、现金转换周期、应收账款 / 营收、存货 / 总资产。周转天数按 365 日口径。 |
| 超预期、持仓与分析师 | SUE、基金持仓比例、机构覆盖度、预测分歧、预期利润增长、60 日预测修正、60 日上调比例、基金持仓比例季度变动。SUE 使用仓库 DFZQ 季节性 SUE 的原始计算。 |

**扣非代理列**为 `earnings_yield`、`earnings_yield_z252`、`deducted_profit_yoy`、`deducted_net_margin`、`deducted_profit_share`，均使用 `n_income_attr_p`。因此代理同比与归母利润同比重复，代理占比在有效非零利润上为 1。数据补齐后需提升派生版本再替换代理。

普通算术组合中的个别缺失组件按零参与，全部缺失留空。分母缺失或为零时比率留空。研发费用率和利息保障倍数的必要字段缺失时留空。空值在派生表中保留，送入网络时替换为零并置缺失标记。

分析师使用 `report_date` 和 `org_name`。每个 60 交易日窗口按机构与预测年度取最近可用年报净利润预测。覆盖度统计机构数，分歧为下一财年预测的标准差 / 均值绝对值。修正和上调比例比较两个相隔 60 交易日的窗口，匹配相同机构、相同目标财年。

基金读取按公告年份分区的 `fund_data/portfolio`，从 `amount` 汇总已披露持股数量，用 `total_share` 换算总股本。每只基金取当前可见的最新报告期。季度变动使用同基金相邻两个可见季度的持股股数差除以当日总股本，只有具备相邻季度的基金进入比较。基金源未到齐的早期日期保留缺失。补齐源后应重新派生受影响日期再训练。

## 派生、训练和预测

派生根为 `data/derived/stock/astgnn_lfq/`。按日期写 `YYYY/YYYYMMDD.parquet`，同级 `manifest.json` 校验指标列和版本。首批如从 2011 年训练，应从 2010 年开始派生以覆盖 120 日输入历史。EP 历史由派生命令向前读取，热身日只在落入请求日期时写出。

两路 GRU 分别提取 alpha 表示和图分支属性，按报告减法聚合 `(I - A) X W`。每个查询块仍对完整当日股票截面求值。训练主损失为 64 个分量的均值与截面标准化 10 日 VWAP 收益之间的 MSE，同时惩罚 alpha 分量之间的相关性。图分支使用 1、5、10 日 VWAP 收益的带岭回归解释损失及相关性惩罚。按验证 MSE 选择权重。原单分数权重需重新训练。普通预测只写等权因子列，[KD-Ensemble](KD_ENSEMBLE.md) 在同一进程中消费这些分量。

每年重训，过去 60 个月中前 57 个月训练、后 3 个月验证。训练截面每 5 个交易日固定采样，每轮完整遍历。公共窗口逻辑以 11 个交易日作为最长标签到期边界。参数在因子 TOML 中，权重写到 `data/model_workspace/astgnn_lfq_daily/artifacts/annual_YYYY/`，预测列进入日频 ML 因子文件。

派生使用公共 HDFS 读取及独立写入调度。训练和预测复用内存中按日连续数组及股票行号，历史 Parquet 在同一流程的后续轮次直接复用。整个流程没有磁盘训练缓存或该因子独有的 I/O 限制。
